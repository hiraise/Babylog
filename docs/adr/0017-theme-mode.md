# ADR-0017: Тема выбирается в приложении и меняется без пересоздания окна

- **Статус:** Принято
- **Дата:** 2026-10-16
- **Затрагивает:** `MainActivity.kt`, `AndroidManifest.xml` (`configChanges`), `core/data/ThemeModeStore.kt`, `core/ui/theme/Theme.kt`, AppCompat в `app/build.gradle.kts`

## Контекст

Тема следовала за системной ([ADR-0010](0010-design-system.md)). Владельцу нужна тёмная тема
ночью, даже когда телефон днём в светлой. Окно до Compose, строка состояния и навигационная
панель красятся из ресурсов (`values-night`) при создании окна, а пересоздание Activity ради
новой темы заметно моргает.

## Решение

- Режим — `ThemeMode` (`SYSTEM`, `LIGHT`, `DARK`), по умолчанию `SYSTEM`. Храни его в
  `ThemeModeStore` (SharedPreferences). Это настройка телефона: в базу и CSV она не попадает.
- Не пересоздавай Activity для смены темы (`recreate()`, `applyOverrideConfiguration`):
  `MainActivity` объявлена с `configChanges="uiMode"` и принимает смену сама.
- Тёмность экрана — `ThemeMode.isDark(isSystemInDarkTheme())`; `MainActivity` передаёт её
  в `BabyLogTheme(darkTheme = …)`.
- Фон окна и системные панели перекрашивай только в `MainActivity.paintWindow` по `background`
  темы: тема окна из ресурсов применяется лишь при его создании.
- На API 31+ дублируй выбор в `UiModeManager.setApplicationNightMode`: заставку при холодном
  запуске и тему окна система берёт уже в выбранной теме.
- Выбор — меню ⋮ → «Тема», нижний лист `ThemeSheet`: три строки в колонку («Как в системе»,
  «Светлая», «Тёмная») с радиокнопками. Тема применяется сразу, лист остаётся открытым.
- AppCompat ради `AppCompatDelegate.setDefaultNightMode` не подключай.

## Последствия

- Смена темы — перерисовка за один кадр; открытые листы и введённый текст не теряются.
- На API 26–30 при холодном запуске с темой, отличной от системной, системная заставка
  мелькает цветом системной темы: заставку рисует система до нашего кода.
- Тему меняет Activity, а не ViewModel: `DiaryScreen` получает `themeMode` и `onThemeModeChange`.

## Проверка

- `ThemeModeTest`: окно открывается в выбранной теме, смена темы перекрашивает то же окно без
  пересоздания, у `MainActivity` в манифесте есть `CONFIG_UI_MODE`.

## Альтернативы

- Пересоздание Activity с подменённой конфигурацией — окно моргает, нижний лист выезжает заново.
- `darkTheme` без перекраски окна — строка состояния и навигационная панель остались бы прежними.
- AppCompat — лишняя зависимость ради одной настройки, и пересоздаёт Activity так же.
