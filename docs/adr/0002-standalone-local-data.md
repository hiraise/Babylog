# ADR-0002: Автономность: данные только на устройстве, сеть — только в интеграциях, включённых пользователем

- **Статус:** Принято
- **Дата:** 2026-10-15
- **Затрагивает:** `app/src/main/AndroidManifest.xml`; любой сетевой код; интеграции и бэкапы; README «Интеграции»

## Контекст

Данные о ребёнке чувствительны, а записывать события нужно всегда — без сети, аккаунтов
и чужих серверов. Вместе с тем отдельные внешние функции полезны: справочная информация,
бэкап в хранилище пользователя.

## Решение

- Все основные функции работают офлайн; данные хранятся только на устройстве.
- Нет своего сервера и учётных записей в приложении; нет аналитики, телеметрии, сторонних
  отчётов о сбоях, рекламы и других трекеров.
- Данные покидают устройство только по явному действию или настройке пользователя.
  Системный автобэкап выключен: `android:allowBackup="false"`.
- Сеть допустима только в интеграциях, которые пользователь включает сам: запросы
  к сервисам за информацией, бэкап в подключённое им хранилище и другие интеграции того
  же рода. Каждая такая интеграция:
  - по умолчанию выключена; без неё и без сети всё остальное работает;
  - передаёт только те данные, без которых не может работать;
  - хранит адреса, ключи и токены, введённые пользователем, только на устройстве —
    в код они не зашиваются;
  - оформляется своим ADR и подразделом README «Интеграции».
- Если задачу решает системный механизм — выбор файла (SAF), «Поделиться», — используй его
  вместо своего сетевого кода: так файл попадёт в любое облако пользователя, а приложению
  не нужен доступ в сеть.
- Permission `INTERNET` добавляется в манифест только вместе с первой сетевой интеграцией
  и её ADR.

## Последствия

- Приложение работает без сети, SIM-карты и аккаунтов; утечь данным с сервера неоткуда.
- Перенос данных — экспорт и импорт CSV ([ADR-0009](0009-csv-with-children.md)) или
  будущие интеграции-бэкапы. Уточнено в [ADR-0033](0033-database-backups.md): перенос между
  телефонами средствами Android 12+ не запрещается.
- Когда появится `INTERNET`, README перестанет быть верным в части «физически не может
  выйти в сеть» — исправь его в том же изменении.

## Проверка

- В `AndroidManifest.xml` нет `android.permission.INTERNET`, пока нет принятого ADR
  о сетевой интеграции; `android:allowBackup="false"`.
