# ADR-0037: «Развитие» — советы и окна навыков ВОЗ по возрасту из файлов приложения, каждый совет сверен с источником

- **Статус:** Предложено
- **Дата:** 2026-10-20
- **Затрагивает:** `feature/development/`, `app/src/main/assets/development/`, `.claude/agents/tips-verifier.md`, `DevelopmentSeenStore`, полоса советов в `TodayContent`, роль навыков в `ChartColors`

## Контекст

Родители хотят знать, что важно в этом возрасте. Открытых API на русском нет; англоязычные (MyHealthfinder,
NHS) запрещают менять текст и требуют сети ([ADR-0002](0002-standalone-local-data.md)). Главный риск —
показать неверное или вырванное из контекста: цифру из раздела о недоношенных как норму для всех.
Где раздел на экране — [ADR-0035](0035-bottom-navigation.md).

## Решение

- Контент — файлы `assets/development/`: `tips_ru.json` (советы) и `who_motor_milestones.json` (окна
  шести навыков ВОЗ — 1-й и 99-й перцентили в днях из таблицы Motor Development Study). Читай встроенным
  `org.json` через интерфейс `TipsSource`; библиотек не подключай. Сеть не используется.
- Совет: `id`, `ageFromDays`, `ageToDays` (в пределах 0–364), `category` (`SLEEP`, `FEEDING`, `DEVELOPMENT`,
  `SAFETY`, `CRYING` — плач и поведение, `HEALTH`), `kind` (`TIP` или `DOCTOR` — «когда показать педиатру»),
  `title`, `summary`, `body`, необязательные `points`, `sources` (название, URL, раздел источника),
  `reviewedAt`; если источники расходятся — `disagreement` с позицией каждого.
- Возраст — полные дни от `Child.birthDate` в поясе устройства, неделя жизни — `дни / 7 + 1`. Без даты
  рождения советов и навыков нет: раздел предлагает её указать. Недоношенность не учитывается.
- Советы недели — те, чей диапазон включает возраст. Точка на «Развитии» и метка «новые» — пока раздел
  не открывали в текущую неделю жизни; отметка — `DevelopmentSeenStore` (`SharedPreferences`, по ребёнку),
  не в базе и не в CSV.
- Источники — только ВОЗ, Минздрав России (клинические рекомендации, приказы), Союз педиатров России,
  CDC, AAP, NHS и рецензируемые статьи ссылкой DOI, как в [ADR-0036](0036-night-day-sleep.md); список
  сайтов — `ALLOWED_SOURCE_HOSTS`. У каждого совета — хотя бы один источник с разделом, откуда взят факт.
- Пиши своими словами со ссылкой; дословно — только официальные документы. Лицензия текстов — как
  у приложения, GPL-3.0-or-later ([ADR-0001](0001-open-source-non-commercial.md)).
- Без доз лекарств, диагнозов и «норма / не норма»: навыки — окнами, тревожные признаки — «обсудите с педиатром».
- Понятия без устоявшейся доказательной базы — «скачки роста» по календарю, «чудесные недели», «регресс
  сна» — не пиши как факт; пиши то, что подтверждает источник (пик плача около двух месяцев). Названия
  чужих программ и методик (PURPLE) не используй.
- Новый или изменённый совет до PR проверяет субагент [`tips-verifier`](../../.claude/agents/tips-verifier.md):
  нет ли искажений и относится ли факт в источнике к тому же возрасту и ситуации. Замечания исправь
  до PR; его отчёт — в описании PR.
- На экранах с советами — источники и «Справочная информация, не заменяет консультацию врача».
- Окна навыков рисуй ролью `ChartColors` с контрастом не меньше 3:1 к карточке во всех палитрах.

## Последствия

- Первая версия — советы на 0–12 месяцев; новые приходят с релизом.
- Скорректированный возраст, рост и вес по нормам ВОЗ, отметки навыков, уведомления — отдельными ADR.

## Проверка

- `TipsContentTest`: схема, уникальные `id`, диапазоны, источник из списка, `reviewedAt` не старше двух лет,
  длина текстов, нет доз (`мг`, `мл/кг`, `МЕ`), на каждую неделю 1–52 есть совет.
- `DevelopmentModelTest`: возраст и неделя, без даты рождения, дата в будущем, навыки «в окне».
- `ThemeContrastTest`: роль навыков во всех палитрах.

## Альтернативы

- API с советами — английский, запрет менять текст, сеть.
- Генерация советов нейросетью — заранее не проверить.
- Советы в коде Kotlin — тексты труднее проверять не программисту.
