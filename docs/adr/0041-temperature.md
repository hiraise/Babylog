# ADR-0041: Температура — запись `Temperature` (тип `TEMPERATURE`) в десятых градуса, место измерения по желанию

- **Статус:** Предложено
- **Дата:** 2026-10-21
- **Затрагивает:** `core/model/` (`Temperature`, `TemperatureMethod`), `EventRecord.kt` (`TEMPERATURE`), `TemperatureSheet`, `parseTemperature`, сводка в `feature/summary/`, `TemperatureChart`, `ChartColors.temperature`, `feature/transfer/`, README «Формат CSV»

## Контекст

Без температуры болезнь ([ADR-0040](0040-illness.md)) теряет главное: ночью мама сверяет замеры
и жаропонижающее, а врач спрашивает, какая была самая высокая и когда.

## Решение

- Температура — разовая запись `Temperature`: `tenths` — десятые градуса (`384` — 38,4 °C) в пределах
  `Temperature.RANGE` (34,0–43,0 °C), `method` — где мерили (`TemperatureMethod`), null — не отмечено.
- `detail` у `TEMPERATURE` — десятые и, если отмечено место, через двоеточие его код: `384`, `384:ARMPIT`
  (как у бутылочки, [ADR-0025](0025-bottle-feeding.md)).
- Ввод — число с клавиатуры, «−» и «+» по 0,1 (`parseTemperature`: «38,4», «38.4» и «384» — одно и то же).
  Значение начинается с прошлого замера, место измерения — как в прошлый раз.
- Приложение не оценивает температуру: без порогов, цветов «высокая» и советов, только значение и время.
  Лист температуры у здорового ребёнка предлагает «Заболел(а)» всегда, а не от какого-то числа.
- Сводка дня — строка «Температура» с самой высокой за день ([ADR-0026](0026-summary-day-totals.md)).
- На экране болезни — линия `ChartColors.temperature` по замерам, под ней — приёмы лекарств
  нейтральными точками по строке на лекарство (`TemperatureChart`).
- В CSV — строка `TEMPERATURE`; версии до 1.9 её не знают и считают ошибкой ([ADR-0009](0009-csv-with-children.md)).

## Проверка

- `EventRecordTest`, `TemperatureInputTest`, `DaySummaryTest`, `CsvImportTest`, `ThemeContrastTest` (`temperature` на карточке).

## Альтернативы

- Температура как заметка с меткой — нет числа: ни графика, ни «самой высокой».
- Только степпер без клавиатуры — от 36,6 до 39,2 — двадцать шесть касаний ночью.
