# ADR-0016: Пол ребёнка — `children.sex` и `detail` строки PROFILE; слова по роду — `bySex`, без пола — мужской род

- **Статус:** Принято
- **Дата:** 2026-10-16
- **Затрагивает:** `core/model/Child.kt`, `core/data/room/Entities.kt`, `feature/transfer/` (`PROFILE`), слова о ребёнке в UI (`bySex` в `core/ui/Format.kt`), `docs/development.md` «Формат CSV»

## Контекст

Интерфейс обращается к ребёнку глаголами прошедшего времени: «Уснул…», «Проснулся», «пописал».
Для девочки они звучат неверно. У прежних детей и в старых CSV пола нет, а файлы любой прежней
версии должны импортироваться ([ADR-0009](0009-csv-with-children.md)).

## Решение

- Пол — `Child.sex: Sex?` (`BOY`, `GIRL`), `null` — не указан. В базе — `children.sex`
  (TEXT, код — имя enum); миграция 4→5 добавляет колонку, у прежних детей `NULL`.
- Слова, меняющиеся по роду, пиши через `bySex(sex, мужской, женский)` из `Format.kt`; пол не
  указан — мужской род. Где звучит естественно, пиши без рода: «Маша спит», «Маша ест».
- Функции, которые выводят такие слова (`eventTitle`, `diaperLabel`, `formatAge`), принимают
  пол параметром без значения по умолчанию: забыть его компилятор не даст.
- Пол выбирают в `ChildSheet` чипами «Мальчик» / «Девочка»; он необязателен.
- В CSV пол — колонка `detail` строки `PROFILE`: `BOY`, `GIRL` или пусто. Новой колонки нет,
  прежние версии приложения эту ячейку не читают.
- Импорт `PROFILE`: пустой пол (файлы до этого ADR) ничего не меняет; неизвестный код — ошибка
  строки; пол из файла ставится, только если у ребёнка его нет; другой пол сообщается,
  текущий остаётся — как дата рождения.

## Последствия

- Выбранный пол снять нельзя — только поменять: `ChoiceChip` повторно не нажимается.
- Новая надпись с глаголом о ребёнке должна получать пол; в превью передавай `sex = null`.

## Проверка

- `MigrationTest` (4→5), `CsvImportTest` (пол из файла, старый файл, неизвестный код),
  `DaySummaryTest` (женские формы), скриншоты с Машей-девочкой.
- `grep -rnE '"[^"]*(снул|оснул|писал|какал|родил)' app/src/main/java` — только внутри `bySex`
  и превью.

## Альтернативы

- Отдельная колонка `sex` в CSV — менять порядок нельзя, а `detail` у `PROFILE` и так пуст.
- Формы «уснул(а)» без пола — читаются канцелярски.
