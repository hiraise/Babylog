# ADR-0014: Иконку, которой нет в Material Symbols, рисуем сами в его начертании

- **Статус:** Принято
- **Дата:** 2026-10-16
- **Затрагивает:** `res/drawable/ic_*.xml`, `core/ui/components/AppIcon.kt`, `core/ui/EventIcons.kt`, README «Лицензия»
- **Заменяет:** часть [ADR-0010](0010-design-system.md) об источнике иконок

## Контекст

По [ADR-0010](0010-design-system.md) иконки берутся из Material Symbols Rounded, но некоторых смыслов
там нет: подгузника, мокрого или грязного, нет (`diaper` не находится). Без правил своя иконка
выбивалась бы из набора по начертанию и по лицензии.

## Решение

- Сначала ищи символ в Material Symbols Rounded; свою иконку рисуй, только если подходящего нет.
- Рисуй вектором `res/drawable/ic_*.xml` с `viewportWidth` и `viewportHeight` 24: только обводка,
  без заливки; `strokeWidth` 1.5, `strokeLineCap` и `strokeLineJoin` — `round`, `strokeColor`
  `#FF000000` (цвет задаёт `AppIcon`). Так штрих совпадает с Rounded wght 300 opsz 24.
- Рисунок вместе со штрихом держи в квадрате 1.5–22.5; зазор между отдельными элементами — от 1.25.
- После XML-пролога пиши комментарий «Своя иконка BabyLog (ADR-0014)» и что на ней изображено.
- Варианты одного предмета рисуй от одной основы: контур тот же, различаются только добавленные
  знаки. Если над основой ничего нет, её можно сдвинуть к центру по вертикали.
- Рисуй сам: чужие иконки (iconmonstr, Flaticon и т. п.) не копируй и не обводи. Своя иконка —
  часть кода проекта под GPL-3.0-or-later ([ADR-0001](0001-open-source-non-commercial.md)).
- Подгузник рисуй с прямым поясом, полукруглым низом, застёжками-язычками по бокам и резинками
  у ног внутри контура. Вырезы для ног на самом контуре не делай: так он похож на трусы.
- Вид подгузника показывай через `diaperIcon(kind)` из `EventIcons.kt`: `ic_diaper_wet` — капля
  внутри («пописал»), `ic_diaper_dirty` — три волны запаха над ним («покакал»), `ic_diaper_mixed` —
  волны и капля («и то, и то»).

## Последствия

- Новый смысл не ждёт символа в Material Symbols, но свою иконку надо сверить с соседними на 24 dp
  в светлой и тёмной теме (витрина `AppIconPreview`) и обновить эталоны скриншотов
  ([ADR-0013](0013-jvm-android-tests.md)).
- В README, «Лицензия», свои иконки перечислены как исключение из Apache-2.0; новую добавляй туда же.

## Проверка

- `grep -L materialsymbolsrounded app/src/main/res/drawable/ic_*.xml` выводит только свои иконки
  и `ic_launcher_foreground.xml`; в каждой своей иконке есть строка «ADR-0014».
- `DiaperIconsScreenshotTest` сверяет иконки подгузника с эталоном `diaper_kinds.png`.

## Альтернативы

- Одна `baby_changing_station` на все виды — вид подгузника не различить без подписи.
- Эмодзи 💧 и 💩 — на разных устройствах выглядят по-разному, ADR-0010 заменил их иконками.
