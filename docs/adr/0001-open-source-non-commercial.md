# ADR-0001: Проект открытый (GPL-3.0-or-later) и некоммерческий

- **Статус:** Принято
- **Дата:** 2026-10-15
- **Затрагивает:** `LICENSE`; зависимости в `*.gradle.kts`; секреты (ключи, токены, пароли)

## Контекст

Владелец развивает приложение как открытый проект без коммерческих целей и не планирует
его закрывать. Это рамка для всех остальных решений.

## Решение

- Лицензия — GPL-3.0-or-later, полный текст — `LICENSE`. Весь код распространяется под ней,
  вклады принимаются на тех же условиях.
- Не требуй от участников CLA или передачи прав на вклады: пока права остаются у авторов,
  перевести проект на закрытую лицензию без их согласия нельзя.
- Весь код и всё, что нужно для сборки, находится в открытом репозитории.
- Никакой монетизации: реклама, платные функции и версии, подписки, встроенные покупки,
  биллинг, сбор и продажа данных пользователей.
- Никакой приватизации: закрытые модули и бинарники без исходников, закрытая «полная»
  версия, перенос разработки в закрытый репозиторий, переход на несвободную лицензию.
- Зависимости, попадающие в APK, — только открытые и совместимые с GPL-3.0: Apache-2.0,
  MIT, BSD, LGPL, MPL-2.0 — можно; EPL-1.0, CDDL, GPL-2.0-only — нельзя. Закрытые SDK
  (Google Play Services, Firebase, рекламные и аналитические) не подключай. Зависимостям
  только для тестов достаточно открытой лицензии.
- Не клади в репозиторий секреты: ключи подписи, токены, пароли.

## Последствия

- Любой может собрать приложение из исходников и проверить, что оно делает с данными.
- Изменённую версию можно распространять только с исходниками под GPL — закрытых форков
  не бывает. Чужие сборки при этом могут быть платными: запрет монетизации касается
  только этого проекта.
- Интеграции со сторонними сервисами строятся без закрытых SDK: через открытые
  библиотеки, HTTP API или системные механизмы Android.

## Проверка

- `LICENSE` — текст GNU GPL v3; в `app/build.gradle.kts` нет `com.google.android.gms`,
  `com.google.firebase`, рекламных и аналитических SDK.

## Альтернативы

- MIT, Apache-2.0 — разрешают закрытые форки, это противоречит запрету приватизации.
- AGPL-3.0 — закрывает «серверную лазейку», а своего сервера у проекта нет
  ([ADR-0002](0002-standalone-local-data.md)).
- GPL-3.0-only — лишает совместимости с будущими версиями GPL.
