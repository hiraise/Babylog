# ADR-0009: CSV с колонкой `child` — формат экспорта и импорта; импорт только добавляет

- **Статус:** Принято
- **Дата:** 2026-10-15
- **Затрагивает:** `feature/transfer/` (`CsvCodec.kt`, `CsvTransfer.kt`), `CsvCodecTest`, `CsvImportTest`, `docs/development.md` «Формат CSV»
- **Заменяет:** [ADR-0005](0005-csv-exchange-format.md)

## Контекст

Облачного автобэкапа нет ([ADR-0002](0002-standalone-local-data.md)), поэтому перенос данных
и резервная копия — файл, который пользователь сохраняет сам; он должен открываться в Excel.
С несколькими детьми ([ADR-0008](0008-data-model-children.md)) у каждой записи в файле
должен быть ребёнок.

## Решение

- Формат: заголовок `type,start,end,detail,note,child`; время локальное, `yyyy-MM-dd HH:mm:ss`;
  экранирование по RFC 4180; UTF-8 с BOM, строки через CRLF. Описание для пользователя —
  `docs/development.md` «Формат CSV».
- Экспорт — весь дневник: строка `PROFILE` на каждого ребёнка (дата рождения в `start`, может
  быть пустой; имя в `child`), затем записи всех детей по возрастанию времени.
- Файл любой прежней версии импортируется новой. Колонки не удаляются, не переименовываются
  и не переставляются; новые добавляются только в конец и необязательны. Строки без `child`
  (файлы до ADR-0008) импортируются к выбранному на экране ребёнку.
- Импорт — слияние в одной транзакции, он ничего не удаляет и не перезаписывает:
  - ребёнок ищется по имени без учёта регистра; не найден — создаётся;
  - запись, совпадающая с существующей у того же ребёнка во всех полях, — дубликат;
  - `SLEEP` без `end` пропускается, иначе появится «фантомный» активный таймер;
  - дата рождения применяется, только если у ребёнка её нет; расхождение сообщается,
    текущая дата остаётся;
  - некорректная строка считается ошибкой и пропускается; ради неё ребёнок не создаётся.
- Любое изменение формата — с тестами в `CsvCodecTest`/`CsvImportTest` и правкой `docs/development.md` «Формат CSV».

## Последствия

- Часовой пояс в файле не хранится: на устройстве с другим поясом записи сохранят
  «настенное» время, а не исходный момент.
- Если ребёнка переименовали после экспорта, импорт старого файла создаст ребёнка
  со старым именем.
