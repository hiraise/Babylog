# Тестовый дневник

Данные — [SeedCsvTest](../../../app/src/test/java/com/kid/babylog/feature/transfer/SeedCsvTest.kt):
«Соня», ~150 дней, ~3300 записей всех типов из `sampleMonths`, время — по сегодня.

1. **Устройство.** На эмулятор, где смотрит владелец, — только по его просьбе: импорт добавит
   ребёнка в его отладочную базу. Для своих проверок — свой эмулятор, его серийник
   в `ANDROID_SERIAL`. На устройстве должна стоять debug-сборка (`scripts/dev.sh run`).
2. **Файл.** `scripts/dev.sh seed` — соберёт CSV и положит его в `/sdcard/Download/`.
3. **Импорт.** В приложении ⋮ → «Импорт из CSV» → в выборе файла `Download` →
   `babylog-seed.csv`. Если открылись «Недавние», где файла от adb нет: «Show roots» (☰) → имя
   устройства → `Download`. Итог — строка «Импорт: добавлено N, новых детей 1».
   Нажатия — по дампу `uiautomator dump` и `input tap`, элемент ищи по точному тексту.
4. **Выбор ребёнка.** Заголовок «Дневник …» → «Соня».
5. **Повторно.** Время отсчитано от сейчас, поэтому второй импорт удвоит записи. Сначала
   удали «Соню»: выбери её → заголовок «Дневник Сони» → карандаш → «Удалить ребёнка…».
6. Скажи владельцу, что «Соня» появилась (или обновилась) в отладочной базе и на каком эмуляторе.

Новый тип записи добавь в `sampleMonths` (`app/src/test/java/com/kid/babylog/testing/SampleMonths.kt`):
`SeedCsvTest` падает, пока в дневнике нет хотя бы одного типа из `EventRecord`. Эталоны
«Аналитики» после этого перезапиши (`scripts/dev.sh goldens`).
